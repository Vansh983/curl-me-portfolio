Simplytest.me is an online portal that gives us the liberty to test any distribution, module or theme. It creates a sandbox for Drupal and installs the projects that we require. It ensures that the usage and working of every Drupal project provides full satisfaction. It also enables us to test the projects in different versions of Drupal. Simplytest.me is an awesome tool for users, both developers and non developers. Why not be sure of the details of a distribution, module or theme you are about to integrate in your website?

### Features of simplytest.me:

- #### Its simple and easy

  The workflow of simplytest.me is very simple and easy. It just requires you to select projects and does the rest of the work for you.

- #### Multiple Versions

  If you are working with an older version of Drupal and want to test whether or not a particular project works with your version or not, Simplytest.me helps you there by giving you multiple options of available versions of the project.

- #### A whole day to work

  It gives us 24 hours to test anything for your website before actually integrating it. So we can test as many projects as we want.

- #### User Satisfaction

  The user, be it a developer or not, gets to test the workflow of each project he wants to work on and be fully satisfied with the project before integrating it on his website.

- #### Smooth Design

  The Design scheme matches with Drupal's, that is a smooth blue-white scheme.

- #### Safe and Sound

  Some projects might not work properly with your website servers, which might lead to server crash and data loss. Simplytest.me would help you to not use these projects.
